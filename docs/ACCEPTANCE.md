# 验收清单

- [ ] doctor环境和流程文件检查。
- [ ] 六阶段交付演示、四阶段工程演示完成，远程调用0。
- [ ] 正式Prompt、import、approve、下阶段全链路运行。
- [ ] 未审批、过期Prompt、缺章节、非法路径拒绝。
- [ ] 输入、角色、成果、前置批准变化使下游失效。
- [ ] 无显式授权或凭证时不调用；三类协议模拟测试通过。
- [ ] 超时、失败、截断有明确行为，次数可查。
- [ ] 看板只读、Host校验、无任意文件访问。
- [ ] 桌面/窄屏、成果预览与刷新可用。
- [ ] 测试、语法、有限扫描、PR契约与CI通过。
- [ ] 用户真实供应商与凭证完成线上联调。
- [ ] 人工审核并批准合并，生产另立任务。

已做证据见VALIDATION.md；最后两项不得由演示或协议模拟替代。
